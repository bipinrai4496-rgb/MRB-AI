Online generation connection

Connect real online AI

To make image, video, music and chat generation happen online inside this website, MRB AI needs a backend server that calls AI providers. GitHub Pages alone cannot safely store secret API keys or run private server code.

Safe connection design

  1. Deploy a small backend (for example, a serverless function).
  2. Store provider API keys as backend environment secrets, never in this HTML file.
  3. Configure the backend to expose an endpoint for image, video, audio and chat requests.
  4. Connect this page to that endpoint and handle provider limits, errors and job status.

This saves only the endpoint address in this browser. Do not enter API keys here. No provider has been connected yet, so online generation will not work until a real backend is deployed and configured.
